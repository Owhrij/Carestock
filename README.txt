CareStock PHP Prototype

Files:
- index.php: the original CareStock website prototype, preserved with the same HTML, CSS, and JavaScript.

Run locally:
1. Install PHP (or XAMPP).
2. Put index.php in your server's web root (for XAMPP, usually C:\\xampp\\htdocs\\carestock\\).
3. Start Apache.
4. Open http://localhost/carestock/ in your browser.

Important:
This is the same front-end demo wrapped in a PHP file. Its sample inventory is still held in browser-side JavaScript and is not saved to a database or shared between computers. No backend inventory/database features were added, in order to preserve the original code and behavior as requested.
